# SWIFTLETHUB – SwiftletHub Knowledge Platform

เว็บไซต์คลังความรู้เรื่อง **นกแอ่น** และ **รังนกแท้** ระดับพรีเมียม (Educational Content-First Platform) ออกแบบและพัฒนาในสไตล์ **Premium Editorial Magazine & Luxury Asian Heritage** เพื่อให้ความรู้ที่ถูกต้อง น่าเชื่อถือ และเคารพธรรมชาติ โดยให้นกแอ่นเป็นศูนย์กลางของอัตลักษณ์ทางภาพ

---

## 🌟 จุดเด่นของแพลตฟอร์ม

- **Content-First & Non-E-Commerce**: ให้ความสำคัญกับเนื้อหาเชิงการศึกษา ไม่ใช่ร้านค้าออนไลน์
- **Swiftlet-Centric Visual Identity**: ใช้ภาพถ่ายจริงของนกแอ่น ถิ่นอาศัย ถ้ำหินปูน และบ้านนกแอ่นเป็นภาพหลัก หลีกเลี่ยงภาพบรรจุภัณฑ์สินค้า
- **Brand Colors (60 / 30 / 10 Proportion)**:
  - 60% – Deep Royal Navy (`#0F2C59`)
  - 30% – Metallic Gold (`#D4AF37`)
  - 10% – Crimson Red (`#C8102E`)
- **Typography**: ภาษาไทยทั้งหมด ใช้แบบอักษร **Noto Sans Thai** รองรับทั้ง Desktop, Tablet และ Mobile
- **Interactive UI**: แถบนำทางแบบ Sticky, คลังบทความพร้อมระบบค้นหาและกรองหมวดหมู่, สารบัญบทความพร้อมแถบแสดงความคืบหน้าการอ่าน (Reading Progress), อินโฟกราฟิกสถิติ, โมดอลรายละเอียดผลิตภัณฑ์เพื่อการเรียนรู้ และระบบจำลองการซื้อ-ฝากขายรังนก

## 🗂️ โครงสร้างหน้าและเนื้อหา

1. **หน้าแรก (Home - `index.html`)**:
   - **Section A: Hero Section** — ภาพนกแอ่นบินเหนือผาหินปูนทะเลอันดามัน พร้อมคำโปรย "เปิดโลกแห่งนกแอ่น เรียนรู้ทุกเรื่องราวของรังนก"
   - **Section B: รู้จักนกแอ่น (Introduction to Swiftlets)** — ข้อเท็จจริง 5 ด้าน และตัวเลขสำคัญ
   - **Section C: คลังความรู้เกี่ยวกับรังนก (Featured Articles)** — บทความไฮไลต์ 3 หัวข้อหลัก
   - **Section D: เรื่องน่ารู้เกี่ยวกับนกแอ่น (Swiftlet Knowledge)** — การ์ดความรู้ 6 หัวข้อ (กายภาพ, วงจรชีวิต, แหล่งอาศัย, การสร้างรัง, ระบบนิเวศ, การอนุรักษ์)
   - **Section E: สถิติและข้อมูลอุตสาหกรรมรังนก (Statistics)** — แดชบอร์ดอินโฟกราฟิก กราฟแท่ง กราฟเส้น โดนัทชาร์ต และห่วงโซ่อุตสาหกรรม (ระบุป้ายข้อมูลตัวอย่างอย่างชัดเจน)
   - **Section F: ผลิตภัณฑ์รังนกที่น่าสนใจ (Product Recommendations)** — แนะนำผลิตภัณฑ์เพื่อการศึกษาในขนาดกะทัดรัด พร้อมโมดอลดูคุณลักษณะ
   - **Section G: บริการเชื่อมโยง (Call to Action)** — "สนใจซื้อหรือฝากขายรังนก?" เชื่อมโยงสู่หน้าการค้า
   - **Section H: ส่วนท้าย (Footer)** — พื้นหลัง `#2A0E10` พร้อมโลโก้ เมนูนำทาง ข้อมูลติดต่อ และโซเชียลมีเดีย
2. **ห้องสมุดบทความ (Articles - `articles.html`)**:
   - ค้นหาแบบเรียลไทม์ (Search Bar)
   - กรองตาม 4 หมวดหมู่หลัก (นกแอ่นและธรรมชาติ, เกรดรังนก, สถิติรังนก, รังนกแท้และรังนกปลอม)
   - แท็กยอดนิยม, บทความเด่น, บทความยอดนิยม และระบบแบ่งหน้า (Pagination)
3. **หน้ารายละเอียดบทความ (Article Detail - `articles/<slug>.html`)**:
   - ครบทั้ง 14 บทความเชิงลึก
   - แถบความคืบหน้าการอ่าน (Reading Progress Bar)
   - สารบัญเนื้อหาแบบ Sticky (TOC) พร้อม Scroll Spy
   - ตารางเปรียบเทียบข้อมูล (Comparison Tables)
   - กรอบข้อความเน้นย้ำ (Callouts & Pull Quotes)
   - ข้อมูลผู้เขียน, แหล่งอ้างอิง, ข้อความปฏิเสธความรับผิดชอบ (Disclaimer) และปุ่มแชร์ไปยังโซเชียล
4. **ผลิตภัณฑ์แนะนำ (Product Recommendations - `products.html`)**:
   - จัดแสดงตัวอย่างรังนก 6 รูปแบบ (รังเต็ม, รังเส้น, พร้อมดื่ม, สีทอง, ตุ๋น, ชุดของขวัญ) พร้อมแนวทางการอ่านฉลากและประเมินคุณภาพ
5. **เกี่ยวกับเรา (About Us - `about.html`)**:
   - ประวัติความเป็นมา, พันธกิจ, วิสัยทัศน์, วัตถุประสงค์ 6 ประการ, คำมั่นสัญญา และแผนงานในอนาคต (Roadmap)
6. **ติดต่อเรา (Contact - `contact.html`)**:
   - แบบฟอร์มติดต่อที่ตรวจสอบความถูกต้อง (Form Validation) พร้อมแสดงข้อความตอบรับ และคำถามที่พบบ่อย (FAQ)
7. **เข้าสู่ระบบ (Login - `login.html`)**:
   - หน้าต่างการยืนยันตัวตน สลับระหว่างหน้าเข้าสู่ระบบ, สมัครสมาชิก และลืมรหัสผ่าน พร้อมปุ่มเปิด/ปิดการแสดงรหัสผ่าน
8. **ซื้อ - ฝากขายรังนก (Buy / Consign - `trade.html`)**:
   - **ซื้อรังนก**: รายการประกาศรังนกจากผู้ขายที่ยืนยันตัวตน พร้อมเกรด รูปทรง แหล่งที่มา และปุ่มติดต่อผู้ขาย
   - **ฝากขายรังนก**: แบบฟอร์มส่งข้อมูลและรูปภาพเพื่อฝากขาย พร้อมระบบแสดงภาพตัวอย่างก่อนส่ง (Upload Preview)
9. **หน้า 404 (Not Found - `404.html`)**:
   - หน้าแจ้งเตือนเมื่อไม่พบบทความหรือหน้าที่ต้องการ พร้อมปุ่มพากลับสู่หน้าแรก

## 🛠️ เทคโนโลยีและการทดสอบ

- **HTML5 & Vanilla CSS/JS**: โหลดเร็ว ปลอดภัย ไร้ dependency ภายนอก
- **Google Fonts**: Noto Sans Thai
- **SEO Ready**: มี Open Graph, Twitter Cards, Semantic Tags, Schema.org JSON-LD สำหรับทั้งบทความและเว็บไซต์

### คำสั่งใช้งาน

```bash
# ติดตั้ง (ไม่ต้องติดตั้งโมดูลภายนอก)
npm install

# สร้างไฟล์หน้าเว็บทั้งหมด (8 หน้าหลัก + 14 หน้าบทความ)
npm run build

# ตรวจสอบความถูกต้องของลิงก์และไฟล์รูปภาพทั้งหมด
npm run verify

# เปิดเซิร์ฟเวอร์ดูตัวอย่างที่ http://localhost:8080/
npm start
```
